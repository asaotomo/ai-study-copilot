## 使用

1. **打开学习页面。** 同意当前协议并开启采集后，扩展会整理页面中已经加载的题目。悬浮图标上的数字表示已收录的题目数量。
2. **打开面板。** 点击悬浮图标，在数据列表中勾选题目，再发送给 AI。
3. **图片和画布。** 使用截图识题，截取当前网页可视区域。发送前看一眼画面里还有没有其他内容。
4. **翻译。** 选择目标语言后点击翻译。划词默认先显示翻译按钮，点击后才发送请求。
5. **留下来。** 需要复习的解析可以存入灵感本。VIP 可以把笔记文字加入答题知识库。
6. **再看一遍。** 历史里可以搜索、置顶、复制，也可以做普通导出。VIP 可以生成复习稿和精排报告。

界面支持中文和英文切换。

默认快捷键可以在「高级设置」里修改：

| 快捷键 | 作用 |
| --- | --- |
| `Alt + Shift + A` | 显示或隐藏面板 |
| `Alt + Shift + B` | 显示或隐藏悬浮图标 |
| `Alt + Shift + S` | 截图识题 |
| `Alt + Shift + T` | 开始翻译 |
| `Alt + Shift + R` | 恢复原文 |
| `Alt + Shift + L` | 开关划词翻译 |

浏览器内部页面无法响应这些快捷键。与系统或浏览器保留键冲突的组合无法覆盖，录入时会提示换一个组合。

## 使用边界

本产品用于合法、获授权的学习辅助与知识整理。请遵守学校、考试组织方、课程平台和网站的使用规则。

请勿用于禁止 AI 或外部辅助工具的考试、认证、测评、面试及岗位考核，也不要用于代考、自动提交答卷或规避平台限制。生成内容仅供学习参考，重要结论请结合教材、原始资料和自己的推导核对。

历史记录、笔记和本地上传的笔记附件默认保存在浏览器本地。解析、翻译和报告生成会把完成任务所需的内容发送到所选服务；启用知识库时，其中可能包含相关笔记片段。开启「即划即翻」或动态网页翻译后，会按设置发送相应待译内容。

截图可能包含同一视区中的其他信息，请在发送前检查。首次验证、官方云端 AI 和联网搜索需要网络。已验证且未到期的 VIP 可以使用本地功能，以及已经在运行的本地模型。账户核验、用量记录和第三方服务的处理方式，以扩展内隐私政策为准。
